## Take1



```

회사에서 KICE 라는 이름으로 역량평가 시험이 있어.
여러과목이 있지만 내가 속한 과목은 CDS-Azure 라는 과목이야
CDS 는 Cloud, Data, Secure 의 약자인데 사실상 CLoud 에 집중되어 있고 게다가 Azure 에 한정되어 있어.


그리고, Azure 중에서도 대략적인 시험범위가 나와 있어서 이를 기반으로 시험준비를 할거야.
시험범위의 내용을 기반으로 예상문제를 만들어서 그 예상문제로 공부를 시작하고 싶어.


1. 제공하는 파일 설명
내가 관련된 자료를 줄테니 예상문제를 만들어줘.
내가 제공하는 자료는 아래와 같아.


1) Pilot 시험문제(2024-KICE기출문제.md)
얼마전 회사에서 실시한 Pilot 시험 문제
문제와 정답, 해설, 추가해설(이건 내가 추가한 내용)
Pilot 시험문제는 이전에 실시했던 시험문제이니 그대로 나올 가능성은 적을꺼야.
시험 형식만 참고하면 될것 같아.

2) 출제동향(출제동향_v1.4_53개.md)
이번에 실시한 시험에 대한 시험범위를 구했어.
항목별 링크가 있고 각 항목별 공부해야 할 핵심 방향도 작성해 놓았어.


3) 항목별 핵심 출제 포인트(항목별 핵심 출제 포인트.md)
자주 출제되는 포인트 및 핵심 학습 방향으로 예상되는 내용으로 구성.



2. 상세조건
- Pilot시험 형식으로 문제를 만들어줘
- 각 문항별로 문제, 정답, 해설 이 있어야 해.
- 시험범위 및 항목별 핵심 출제 포인트를 기반으로 문제를 생성해야 해
- 4지선다 의 보기가 있는데 맞는것은? 또는 틀린것은? 이라는 문제를 적절히 생성해줘. 비율은 약 6:4 정도로
- 맞는것은? 이라는 문제에서 틀린 보기도 헷갈릴만한 보기들로 구성이 되어야 해.
- 보기에서 유난히 긴 문장의 보기가 정답인 사례가 많던데, 이렇게 문장의 길이만으로 정답을 유추할 수 있는 상황은 패해줘.
- 맞는것은? 의 문제일때, 맞는것은 왜 맞았는지, 틀린보기는 왜 틀렸는지 해설에 꼼꼼하게 작성해줘.
- 다시 말하지만 시험 응시자들이 실제 시험을 위해 학습하기 위함이야. 그러므로 해설이 길어도 되니 가능한 상세하게 작성해줘.
- 또한 출제범위(시험범위) 내에서만 문제를 작성해야 해.


3. 카테고리
전체 영역의 카테고리는 아래와 같이 5개 카테고리로 분류하는 것이 좋겠어.
1. Azure 기본 서비스 & 거버넌스
2. 스토리지 & 데이터 관리
3. 네트워크 & 보안
4. AKS / Kubernetes
5. CI/CD & 비용 최적화


카테고리의 순서와 문제의 순서는 동일하게 맞춰줘.

4. 문제 형식 및 결과 파일 종류
완성된 문제들은 Markdown, CSV, 엑셀 이렇게 3개의 파일이 필요해.
각 문항별로 아래와 같이 분류했으면 좋겠어.
예를들어, 엑셀파일의 경우 아래 컬럼으로 구성되어야 할듯해 
컬럼 예시: 카테고리 | 문항번호 | 문제 | 보기ABCD | 정답 | 해설 | 문제주제 | 관련링크 | 난이도 | Top50여부




1) 해설
해당문제는 시험 응시자들이 실제 시험을 대비하기 위해 사전에 풀어보는 의미가 있어.
그러므로 가급적 많은 학습을 할 수 있도록 도움이 될 수 있는 관점으로 만들었으면 좋겠어.
해설의 설명을 보면서 많은 공부를 할 수 있도록 하고 싶어.
좀더 상세히 작성해줘.

2) 주제
문제별로 각각 다른 주제를 다뤘으면 좋겠어. 주제를 간략히 작성해줘.
중복되는 문제가 있으면 안됨.



3) 관련링크
해설에 이어 그림이나 아키텍처의 설명이 필요하다면 링크도 추가해줘.
아마도 MS 공식 가이드문서 페이지가 그 대상이 되겠지.
예를들어 
핵심 주제가 Azure Storage의 데이터 중복성(Data Redundancy)이라면
관련링크는 "Azure Storage 중복성"과 관련된 링크인 아래가 되어야 할듯 해.
관련링크
 - Azure Storage 중복성 : https://learn.microsoft.com/ko-kr/azure/storage/common/storage-redundancy
응시자들은 그림이나 아키텍처가 있는 링크를 보면서 공부할 수 있도록 했으면 좋겠어.
가급적이면 한글문서페이지로 안내해줘.


4) Top50 선별
200문제를 응시생들과 함께 문제풀이하는 시간을 갖을꺼야.
200개중 핵심이라고 생각되는 문제 50개를 골라서 "Top50" 이라는 컬럼으로 표기해줘.
당연한 이야기 이겠지만 출제동향 파일에서 "출제빈도: 상"이라고 되어 있는 것들은 Top50 에 포함되어야 겠지.

## 문항 3.
김선임은 C고객사의 시스템을 운영 중 Private 네트워크에서만 접근해야 하는 중요 파일 저장용 Storage Account에 퍼블릭 접근 권한을 실수로 부여하였다. 일주일 후 해당 조치가 문제가 있다는 것을 확인하여 퍼블릭 접근 권한을 회수 조치하였다. 추후 동일 이슈가 발생하지 않도록 변경사항에 대해 사전에 자동으로 모니터링될 수 있도록 방안을 수립하기로 하였다. 다음 중 적절하지 못한 것을 고르시오. [4점]
A. Azure Policy를 적용하여 퍼블릭 접근이 허용된 Storage Account에 대해 Audit Log를 남기고 알람을 발생시키도록 한다.
B. Azure Automation을 활용하여 주기적으로 퍼블릭 접근이 허용된 Storage Account을 확인하고 조치할 수 있도록 한다.
C. Azure CLI를 활용하여 Resource Graph에 질의하여 private endpoint가 구성되지 않은 Storage Account을 확인하고 수정할 수 있도록 한다.
D. Azure 활동 로그 이벤트를 수신할 수 있는 Event Grid와 Logic Apps를 활용하여 퍼블릭 접근 권한이 부여되는 Storage Account을 확인하고 수정할 수 있도록 한다.
E. Storage Account에 진단 설정을 활성화하여 익명 요청이 성공한 Storage Account을 확인하고 수정할 수 있도록 한다.
```
