



# 1. 지역서비스와 비지역서비스



특정 리소스가 특정 지역에 종속되는지 여부에 따라 분류된다.

이 구성은 배포, HA 설계, 거버넌스(보안/규정) 에 매우 중요하다.



## 1) 지역서비스(Regional Service)

Azure 리소스가 특정 리전에 물리적으로 배포되고 리전에 종속적인 서비스를 의미



### 대표적인 지역서비스



| **서비스**                           | **설명**                           |
| ------------------------------------ | ---------------------------------- |
| **Virtual Machines (VM)**            | 특정 Region에 배치                 |
| **Virtual Network (VNet)**           | Region 단위로 생성                 |
| **Azure Kubernetes Service (AKS)**   | Region 단위 클러스터               |
| **Azure App Service**                | Region 기반으로 웹앱 호스팅        |
| **Azure SQL Database**               | 데이터베이스가 특정 Region에 생성  |
| **Azure Storage (Standard LRS/ZRS)** | 스토리지 계정이 특정 Region에 존재 |



## 2) 비지역서비스(Non-Regional Service, Global Service)

리소스가 특정 지역에 종속되지 않고 , 전역 또는 Azure Platform 전체에서 관리되는 서비스를 의미

리소스 생성시 Region 을 명시하지 않고 생성



대표적인 서비스

| **서비스**                            | **설명**                           |
| ------------------------------------- | ---------------------------------- |
| **Azure Active Directory (Entra ID)** | 전역 인증 서비스, Region 선택 없음 |
| **Azure DNS**                         | 전역 DNS 레코드 관리               |
| **Azure Traffic Manager**             | 전 세계 트래픽을 Region별로 분산   |
| **Microsoft Defender for Cloud**      | 중앙 관리형 보안 모니터링          |
| **Azure Policy / Management Group**   | 전역 거버넌스 정책                 |
| Azure DevOps                          |                                    |
|                                       |                                    |





## 3) 예시비교

| **시나리오**          | **지역 서비스**           | **비지역 서비스**            |
| --------------------- | ------------------------- | ---------------------------- |
| VM 배포               | 특정 Region 선택 필수     | 불가                         |
| 인증 및 사용자 관리   | Entra ID (Global)         | 해당 없음                    |
| Global Load Balancing | Traffic Manager           | 해당 없음                    |
| 지역 장애 발생 시     | 해당 Region 리소스만 영향 | 대부분 영향 없음             |
| 정책 일괄 적용        | 불가능 (리소스 단위)      | Azure Policy로 가능 (전역적) |
